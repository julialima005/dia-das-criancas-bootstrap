# Dia das Crianças 🎈

Projeto acadêmico desenvolvido durante a graduação em Engenharia de Software na UDF, utilizando HTML, Bootstrap e Font Awesome.

## Sobre o projeto

Site informativo sobre o Dia das Crianças, com textos sobre a história da data, a importância das brincadeiras e os direitos das crianças.

O objetivo é praticar a organização de páginas e o uso de componentes do Bootstrap.

## Recursos

- Menu com links para as seções da página.
- Carrossel de imagens.
- Cartões com imagens e textos.
- Janela de mensagem especial (modal).
- Perguntas e respostas expansíveis (accordion).
- Ícones do Font Awesome.

## Tecnologias utilizadas

- HTML5.
- Bootstrap 5.3.8: estilos, organização em colunas e componentes interativos.
- Font Awesome: ícones.

## Como executar

1. Clique em **Code → Download ZIP**.
2. Extraia o ZIP.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências: os arquivos utilizados estão incluídos no projeto.

Para baixar usando Git:

```bash
git clone https://github.com/julialima005/dia-das-criancas-bootstrap.git
cd dia-das-criancas-bootstrap
```

Depois, abra `index.html` no navegador.

## Organização

- `index.html`: conteúdo e estrutura do site.
- `css/`: estilos do Bootstrap.
- `js/`: scripts do Bootstrap.
- `img/`: imagens do projeto.
- `fontawesome/`: estilos, fontes de ícones e licença do Font Awesome.

## Limitações atuais

- A pesquisa é apenas visual e não realiza buscas.
- Os botões “Saiba mais” e os itens do menu suspenso ainda não têm destinos específicos.

## Aprendizados

Prática de navegação por identificadores, organização em colunas e utilização de carrossel, cartões, modal e accordion.
